# LCR Logger

HIOKI LCR 미터를 USB로 연결해 인덕턴스 측정값을 받아 CSV 파일로 저장하는 프로그램입니다.
CSV 파일은 엑셀에서 바로 열 수 있고, 구글 스프레드시트에서 불러올 수 있습니다.

- **개발자:** KIM YEONGDO
- **다운로드:** [Releases](https://github.com/Dubitnarae/LCR_Logger/releases/latest)에서 `LCR_Logger_v<버전>.zip`을 받아 압축을 풉니다.

## 자동 업데이트와 새 버전 배포

프로그램은 시작할 때(그리고 **업데이트 확인** 버튼을 누를 때) GitHub API `releases/latest`를 조회합니다.

- **판별:** 릴리스 태그(`v1.5` 등)가 실행 중인 버전보다 높으면 사용자에게 묻습니다.
- **교체:** 릴리스에 첨부된 `LCR_Logger.exe`를 `LCR_Logger.exe.new`로 받아 검사(MZ 헤더, 크기, GitHub가 제공하는 SHA-256 digest)합니다.
  그런 다음 실행 중인 exe를 `.old`로 이름 바꾸고 새 exe를 넣은 뒤 다시 시작합니다. `.old`는 다음 실행 때 지웁니다.
- **실패 시:** 네트워크 오류나 쓰기 권한 문제가 있으면 기존 버전을 그대로 씁니다.

새 버전 배포 순서:

1. `src\LcrLogger.cs`의 `AssemblyVersion`/`AssemblyFileVersion`을 올립니다(예: `1.5.0.0`).
2. 변경을 커밋하고 `git push`합니다.
3. `publish_release.bat "변경 내용"`을 실행합니다. 빌드 → zip 생성 → `gh release create v1.5`로 exe와 zip을 올립니다.

저장소는 공개(public)여야 프로그램이 로그인 없이 릴리스를 받을 수 있습니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `LCR_Logger.exe` | 실행 파일. 설치 없이 더블클릭으로 실행합니다. |
| `data\` | 측정 데이터(CSV)가 저장되는 기본 폴더. 첫 측정 때 자동으로 만들어집니다. |
| `src\LcrLogger.cs` | 소스 코드 |
| `build.bat` | 소스를 고친 뒤 다시 빌드할 때 실행합니다. |
| `make_release.bat` | 빌드한 뒤 배포용 `release\LCR_Logger_v<버전>.zip`을 만듭니다. zip에는 exe와 `사용설명서.txt`가 들어갑니다. |
| `publish_release.bat` | `make_release.bat` 후 GitHub 릴리스를 만들어 자동 업데이트로 배포합니다. |
| `사용설명서.txt` | 측정 PC 사용자용 설명서. 배포 zip에 포함됩니다. |

**배포 버전의 동작**
- **저장 위치:** 기본 저장 위치는 `문서\LCR_Data`입니다.
- **설정 저장:** 저장 폴더, 단위 등 설정은 `%APPDATA%\LCR_Logger\settings.ini`에 저장됩니다.

## IM3536 준비 (처음 한 번)

1. **USB 드라이버 설치:** HIOKI 홈페이지에서 IM3536용 USB 드라이버를 받아 PC에 설치합니다.
   - 설치하지 않으면 COM 포트가 생기지 않습니다.
   - 샘플 앱의 다운로드 페이지에 같이 있는 경우가 많습니다.
2. **인터페이스 설정:** IM3536 본체에서 인터페이스를 **USB**로 설정합니다.
3. **측정 항목 설정:** 측정 항목(PAR1~PAR4)에 **Ls**(직렬) 또는 **Lp**(병렬)를 넣습니다.
   본체에서 해도 되고, 프로그램의 "연결 시 PAR1"에서 `LS`를 골라도 됩니다.
4. **연결 확인:** USB 케이블을 꽂으면 포트 목록에 ★가 붙은 COM 포트가 나타납니다.

**측정값 받는 방식은 두 가지입니다.**

- **기본 (INT 트리거):** 계측기가 계속 측정하고 있고, 버튼을 누르면 그 순간의 최신값을 받습니다.
- **EXT 트리거:** 버튼을 누를 때마다 새로 한 번 측정하고 그 결과를 받습니다. 시료를 바꿔 끼우며 하나씩 기록할 때 정확합니다.
  - 아래 **직접 명령** 칸에서 `:TRIG EXT`를 보내 계측기를 EXT 트리거로 바꿉니다.
  - **누를 때마다 새로 측정**을 체크합니다.
  - 원래대로 되돌리려면 `:TRIG INT`를 보냅니다.

## 사용 방법

1. **계측기 설정:** LCR 미터의 인터페이스를 **USB**로 설정합니다.
2. **USB 연결:** USB(A-B) 케이블로 PC와 연결합니다. 장치 관리자의 "포트(COM & LPT)"에 COM 포트가 생겨야 합니다.
   포트가 보이지 않으면 HIOKI 홈페이지에서 해당 모델의 USB 드라이버를 설치하세요.
3. **연결:** 프로그램을 실행하면 HIOKI 장비가 포트 목록에 **★**로 표시됩니다. 포트를 고르고 **연결**을 누르세요.
   - 연결되면 모델명과 측정 파라미터(PAR1~PAR4)를 읽어 와 표의 열을 만듭니다.
   - 계측기에 인덕턴스(Ls/Lp)가 설정되어 있지 않으면 **연결 시 PAR1**을 `LS`로 고른 뒤 다시 연결하세요.
4. **측정:**
   - 한 번 측정할 때는 **측정** 버튼이나 **Enter** 키를 누릅니다. 메모 칸에 시료 이름을 적고 Enter를 치면 편합니다.
   - 반복 측정할 때는 간격과 횟수를 정하고 **연속 측정 시작**을 누릅니다. 횟수 0은 멈출 때까지 계속 측정합니다.
5. **저장:**
   - 측정할 때마다 `data\LCR_날짜_시간.csv` 파일에 한 줄씩 바로 기록됩니다.
   - 저장 버튼을 따로 누르지 않아도 되고, 프로그램이 꺼져도 그때까지의 데이터는 남습니다.

**계측기 없이 시험하기:** **데모 모드**를 체크하고 연결하면 가상 측정값(약 100 µH)으로 모든 기능을 써 볼 수 있습니다.

## CSV 형식

```
No,측정시각,메모,Ls [µH],Q,원본응답
1,2026-10-27 09:46:34,,100.03,4.55083E+01,"1.00030E-04,4.55083E+01"
```

- **인덕턴스 단위:** 인덕턴스는 선택한 단위(H, mH, µH, nH)의 숫자로 저장되어 스프레드시트에서 바로 계산할 수 있습니다.
  단위를 바꾸면 새 파일로 기록을 시작합니다.
- **원본응답:** 계측기가 보낸 문자열을 그대로 저장한 열입니다. 문제가 생겼을 때 확인용입니다.
- **인코딩:** 파일은 UTF-8(BOM) 형식이라 엑셀에서도 한글이 깨지지 않습니다.
- **파일이 열려 있을 때:** 엑셀로 파일을 열어 둔 채 측정하면 기록이 잠시 보류되고, 파일을 닫은 뒤 다음 측정 때 함께 기록됩니다.

## 구글 스프레드시트로 옮기기

1. 구글 스프레드시트에서 **파일 → 가져오기 → 업로드**를 선택하고 CSV 파일을 끌어다 놓습니다.
2. 가져오기 위치를 선택합니다. 예: "새 시트 삽입" 또는 "현재 시트에 행 추가"
3. 구분 유형은 "자동 감지" 또는 "쉼표"를 선택합니다.

## 원본 프로그램 분석 결과

`LCRMeterSampleApplicationEN140.msi`는 HIOKI의 "LCR Meter Sample Application" 1.4.0(VB.NET)입니다.
설치하지 않고 내용만 풀어서 분석했습니다. 확인한 내용은 다음과 같습니다.

- **지원 모델:** IM3536, IM3523, IM3533(-01), IM3570, IM3590, IM7580, LCR3511
- **USB 연결 방식:** 가상 COM 포트를 씁니다. WMI로 포트 장치를 찾고 HIOKI USB VID `108F`로 구분합니다.
  시리얼 설정은 RTS 사용, 터미네이터 CR+LF입니다.
- **사용 명령:**
  - `*IDN?`: 모델 확인
  - `:HEAD OFF`: 응답에 헤더를 붙이지 않음
  - `:PAR1?`~`:PAR4?`: 측정 파라미터 확인
  - `:MEAS?`: 측정값 요청. PAR1~PAR4 중 OFF가 아닌 값이 쉼표로 구분되어 순서대로 옵니다.
  - `*TRG`: 외부 트리거

이 프로그램은 위 방식 그대로 통신합니다.

## 알아둘 점

- **확인된 범위:** 데모 모드와 자체 점검(`LCR_Logger.exe --selftest`)으로 화면, 값 환산, CSV 기록을 확인했습니다.
  실제 계측기 연결은 아직 시험하지 않았습니다.
- **IM3570:** `:MEAS?` 출력 항목을 `:MEAS:ITEM`으로 따로 정합니다.
  값 개수가 맞지 않는다는 경고가 나오면 아래 **직접 명령** 칸에서 출력 항목을 설정하세요.
- **LCR3511:** 명령 체계가 달라 지원하지 않습니다.
- **트리거 설정:** EXT 트리거로 쓸 때는 위의 "IM3536 준비"를 참고하세요.
  이때 프로그램은 `*TRG;:MEAS?`를 한 줄로 보내 측정이 끝난 뒤의 값을 받습니다.
- **연속 측정(CONT) 모드:** 이 모드에서는 `:PAR1?` 같은 LCR 모드 명령에 계측기가 응답하지 않습니다.
  원본 샘플 앱은 연속 측정 모드를 패널 설정 저장·불러오기에만 쓰고,
  측정값은 받지 않습니다(`:CONT:EXEC? n` → ON/OFF, `:CONT:COUN?`).
  - 그래서 1.1부터는 **다중 주파수 측정**으로 대신합니다.
    LCR 모드에서 `:TRIG EXT` → 주파수마다 `:FREQ f` + `*TRG;:MEAS?` 순서로 측정하고, 끝나면 원래 주파수와 트리거로 되돌립니다.
  - 연결할 때 `:MODE?`가 LCR이 아니면 `:MODE LCR`로 바꿀지 물어봅니다.
- **스프레드시트 바로 입력(1.2):** 전역 단축키(`RegisterHotKey`, 기본 F9)를 누르면 측정한 뒤, 단축키를 누른 순간 활성화돼 있던 창에 값을 입력합니다.
  - 입력은 `SendInput` 유니코드 키 입력이라 한/영 상태와 관계없습니다.
  - 값은 지수 표기 없는 소수로 입력하고, 값 사이와 끝에 Tab/Enter를 보냅니다.
  - 측정 중에 활성 창이 바뀌면 입력하지 않습니다.
  - 아직 실제 엑셀/구글 시트에서는 시험하지 않았습니다.
- **IM3536 측정 항목 이름:** Z, Y, PH(θ), RS, RP, CS, CP, D, G, X, LS, LP, Q, B, DC(Rdc), S(σ), E(ε)이며,
  원본 앱에서 확인했습니다. 각각 단위를 붙여 열 제목을 만듭니다.
- **직접 명령:** 화면 아래 **직접 명령** 칸에 명령을 입력하면 계측기와 직접 통신할 수 있습니다(예: `:FREQ?`).
