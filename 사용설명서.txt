LCR Logger 1.25 사용설명서
개발자: KIM YEONGDO  /  https://github.com/Dubitnarae/LCR_Logger

처음 실행하면 바로 아래처럼 측정하도록 설정되어 있습니다.
  - 측정 주파수 4개: 1kHz, 100kHz, 200kHz, 1MHz (다중 주파수 측정 켜짐)
  - 측정값: Ls (연결할 때 계측기의 PAR1을 Ls로 설정. PAR2~PAR4는 변경 안 함)
  - 스프레드시트 입력: 주파수별 Ls 값 4개, 단위 µH
============================================================

HIOKI IM3536 LCR 미터로 측정한 인덕턴스 값을 USB로 받아
CSV 파일(엑셀, 구글 스프레드시트에서 열 수 있음)로 저장하는 프로그램입니다.
설치 과정 없이 실행 파일 하나로 동작합니다.


■ 필요한 것
------------------------------------------------------------
- Windows 10 또는 11 PC
- HIOKI IM3536 LCR 미터와 USB 케이블(A-B)
- HIOKI IM3536 USB 드라이버 (처음 한 번만 설치)


■ 처음 한 번만 하는 준비
------------------------------------------------------------
1. 압축 풀기
   받은 zip 파일을 마우스 오른쪽 버튼으로 눌러 [압축 풀기]를 하고,
   풀린 폴더를 바탕화면 등 원하는 곳에 둡니다.
   ※ zip 안에서 바로 실행하지 마세요.

2. USB 드라이버 설치
   HIOKI 홈페이지(www.hioki.com)에서 "IM3536 USB 드라이버"를 받아 설치합니다.
   설치 후 계측기를 USB로 연결하면
   장치 관리자 → "포트(COM & LPT)" 아래에 COM 포트가 나타납니다.

3. 계측기 설정 (IM3536 본체)
   - 인터페이스를 USB로 설정합니다. (RS-232C·LAN·GPIB로 연결할 때는 그 방식으로 설정)
   - PAR1은 프로그램이 연결할 때 Ls(직렬 인덕턴스)로 설정합니다. 본체에서 따로 바꿀 필요가 없습니다.

4. 처음 실행할 때 파란 경고 창이 뜨는 경우
   "Windows의 PC 보호" 창이 뜨면
   [추가 정보]를 누른 뒤 [실행]을 누릅니다.
   (인증서가 없는 사내 프로그램이라 나오는 경고입니다)


■ 측정하기
------------------------------------------------------------
1. 계측기를 켜고 USB로 연결한 뒤 LCR_Logger.exe를 실행합니다.

2. [1. 연결]
   COM 포트 목록에서 ★ 표시가 붙은 포트(HIOKI 장비)를 고르고
   [연결]을 누릅니다.
   연결되면 오른쪽에 모델명(HIOKI,IM3536,...)이 초록색으로 표시됩니다.

   USB 말고 다른 연결 방식 ([연결 방식]에서 고름, 계측기 본체 인터페이스도 같게 설정)
   - USB / RS-232C: COM 포트를 고릅니다. RS-232C는 [속도]를 계측기와 같게 맞춥니다.
     (USB는 속도와 상관없음)
   - LAN: "IP:포트"에 계측기의 IP 주소와 통신 포트를 적습니다. 예) 192.168.0.1:3500
     포트를 빼고 IP만 적으면 3500을 씁니다. PC와 계측기가 같은 네트워크에 있어야 합니다.
   - GPIB: 계측기에 설정한 GPIB 주소(0~30)를 적습니다.
     PC에 GPIB 카드 드라이버와 NI-VISA(또는 Keysight IO Libraries)가 설치되어 있어야 합니다.
   - 자동 재연결은 모든 방식에서 동작합니다 (LAN·GPIB는 끊기면 같은 주소로 계속 다시 시도).

3. [2. 측정]
   - 한 번 측정: [측정] 버튼 또는 Enter 키
     메모 칸에 시료 이름을 적고 Enter를 누르면 메모와 함께 기록됩니다.
   - 반복 측정: 간격(초)과 횟수를 정하고 [연속 측정 시작]
     (횟수 0 = 멈출 때까지 계속)
   - L 단위: 인덕턴스를 저장할 단위(H, mH, µH, nH)를 고릅니다.

4. [3. 저장]
   측정할 때마다 자동으로 CSV 파일에 저장됩니다. 저장 버튼을 누를 필요가 없습니다.
   - 기본 저장 위치: 문서\LCR_Data\LCR_날짜_시간.csv
   - [폴더 열기]를 누르면 저장 폴더가 열립니다.
   - [새 파일로 시작]을 누르면 다음 측정부터 새 파일에 기록합니다.

   프로그램을 껐다 켜도 저장 폴더, 단위 같은 설정은 그대로 남아 있습니다.


■ 여러 주파수(최대 8개)로 한 번에 측정하기
------------------------------------------------------------
계측기의 "연속 측정(CONTINUOUS)" 모드 대신 이 기능을 사용합니다.
계측기는 일반 LCR 측정 화면 상태로 두면 됩니다.

1. [다중 주파수 측정]의 "사용"이 체크되어 있는지 확인합니다 (기본으로 켜져 있음).
2. 주파수1~8 칸 중 1~4는 기본으로 1k, 100k, 200k, 1M, 5~8은 빈칸입니다.
   바꾸려면 연결하기 전에 고칩니다.   (120 = 120Hz, 1k = 1kHz, 1M = 1MHz)
   쓰지 않는 칸은 비워 두면 건너뜁니다.
3. [연결]을 누른 뒤 [측정](또는 Enter)을 누르면
   입력한 주파수를 차례로 측정해 한 행에 기록합니다.
   예) Ls@1kHz [µH], Ls@100kHz [µH], Ls@200kHz [µH], Ls@1MHz [µH]
   (계측기의 PAR2~PAR4에 다른 항목이 켜져 있으면 그 값도 CSV에 함께 저장됩니다)
4. 측정이 끝나면 계측기의 주파수와 트리거 설정은 측정 전 상태로 돌아갑니다.

주파수를 바꾸려면 [연결 해제]를 누른 뒤 고치고 다시 연결합니다.

※ 계측기가 연속 측정(CONTINUOUS) 모드인 상태에서 [연결]을 누르면
  "LCR 모드로 바꿀까요?"라고 묻습니다. [예]를 누르면 됩니다.


■ 스프레드시트 빈칸에 바로 입력하기 (엑셀, 구글 시트)
------------------------------------------------------------
이미 만들어 둔 스프레드시트에서 셀을 선택하고 단축키를 누르면
측정값이 그 셀에 자동으로 입력됩니다. 프로그램 창을 누를 필요가 없습니다.

1. 프로그램에서 계측기를 [연결]합니다.
2. [4. 스프레드시트에 바로 입력]에서 "사용"을 체크하고 단축키를 고릅니다(기본 F9).
   - 값: "Ls만"(기본, 주파수마다 Ls 하나) 또는 "모든 파라미터"
   - 값 사이: 값이 여러 개일 때 다음 값을 넣을 칸
       Tab = 오른쪽 칸 / Enter = 아래 칸
   - 입력 후: 입력이 끝나고 커서를 옮길 곳
       Enter = 다음 행 / Tab = 오른쪽 칸 / 이동 안 함
3. 엑셀이나 구글 시트(인터넷 창)에서 값을 넣을 첫 칸을 클릭합니다.
4. 시료를 연결하고 F9를 누릅니다.
   측정이 끝나면 "띵" 소리와 함께 값이 입력됩니다.
   실패하면 경고음이 나고, 이유는 프로그램 아래 로그에 남습니다.

예) 기본 설정 (다중 주파수 4개 + "Ls만" + 값 사이 Tab + 입력 후 Enter)
    → 선택한 칸부터 오른쪽으로 1kHz, 100kHz, 200kHz, 1MHz의 Ls 값 4개가 들어가고
      커서가 다음 행으로 내려갑니다.
    (엑셀은 Enter를 누르면 입력을 시작한 열로 돌아갑니다.
     구글 시트에서 다른 칸으로 가면 "입력 후"를 "이동 안 함"으로 하고 직접 다음 칸을 누르세요)

마지막 값 다시 입력 (Shift+F9)
- 셀 위치를 잘못 잡았을 때는 올바른 칸을 클릭하고 Shift+F9를 누릅니다.
  다시 측정하지 않고 바로 앞에 측정한 값을 그대로 다시 입력합니다.
- 단축키를 F9가 아닌 다른 키로 바꾸면 Shift+그 키가 됩니다 (화면에 표시됨).
- 잘못 들어간 칸의 값은 직접 지워 주세요.

주의
- 측정이 끝날 때까지 다른 창을 누르지 마세요.
  창이 바뀌면 안전을 위해 입력하지 않습니다 (CSV 파일에는 저장됨).
- 값은 프로그램에서 고른 L 단위(µH 등) 숫자로 입력됩니다.
- 모든 측정값은 지금처럼 CSV 파일에도 함께 저장되므로 백업이 남습니다.


■ 측정 조건 설정 (PAR, 측정 신호, SPEED, DC 바이어스, 레인지, 평균, 리밋 등)
------------------------------------------------------------
[측정 조건] 칸에서 고른 항목을 [연결]할 때 계측기에 보냅니다.
다중 주파수 측정이면 모든 주파수에 같은 조건이 적용됩니다.

- 측정 파라미터: PAR1은 Ls로 고정입니다 (스프레드시트 입력 "Ls만"이 PAR1의 Ls를 쓰기 때문).
  PAR2~PAR4는 OFF, Z, Y, PHASE(θ), CS, CP, D, LP, Q, RS, G, RP, X, B, RDC, S(σ), E(ε) 중에서 고릅니다.
  같은 파라미터를 두 번 고를 수는 없습니다. 고른 파라미터는 표와 CSV에 열로 추가됩니다.
  스프레드시트에 Ls 외의 값도 넣으려면 [4. 스프레드시트]의 값을 "모든 파라미터"로 하세요.
  ※ RDC를 고르면 계측기가 DC 바이어스를 강제로 끌 수 있습니다. RDC와 DC 바이어스는 같이 쓰지 마세요.
- 측정 신호: 종류를 고르고 값을 입력합니다. V(개방전압) / CV(정전압)는 0.005 ~ 5 V, CC(정전류)는 mA 단위입니다.
  종류를 바꾸면 값 칸이 그 종류의 기본값(1 V / 10 mA)으로 바뀝니다.
- SPEED: FAST / MED / SLOW / SLOW2 중에서 고릅니다.
- DC 바이어스: OFF / ON 중에서 고르고, ON이면 전압을 입력합니다 (0 ~ 2.5 V).
- 그 밖의 항목: 주파수(다중 주파수를 끈 경우), 자동 레인지·레인지(HOLD), LOW Z 모드, 평균 횟수(1~256),
  리밋(ON/OFF·전압 V·전류 A), 트리거 지연, 트리거 동기 출력·대기, Rdc 측정 지연·보정 지연, 전원 주파수.
  입력 범위는 [계측기 설정] 탭의 설명과 같습니다. 빈칸은 바꾸지 않습니다.
  ※ 트리거(INT/EXT)는 [측정]의 "누를 때마다 새로 측정" 스위치로 정하고, PAR1은 Ls 고정입니다.
- "변경 안 함"으로 두면 그 항목은 계측기 설정 그대로 둡니다.

연결 중에 조건 바꾸기
- 연결된 상태에서 값을 바꾼 뒤 [연결 중 적용]을 누르면 바로 계측기에 반영됩니다.
  (누르지 않으면 계측기는 그대로입니다)
- 적용할 때 계측기를 먼저 처음 연결 전 값으로 되돌린 뒤 새 조건을 보냅니다.
  그래서 몇 번을 바꿔도 [연결 해제] 때는 처음 연결하기 전 값으로 돌아갑니다.
- PAR2~PAR4가 바뀌면 표의 열이 달라지므로 새 CSV 파일로 기록을 시작합니다.
  신호 레벨·SPEED·DC 바이어스만 바꾸면 같은 파일에 이어서 기록합니다.

프리셋 (자주 쓰는 조건 저장)
- 원하는 조건을 고른 뒤 [프리셋] 칸에 이름을 입력하고 [프리셋 저장]을 누릅니다.
  예) "인덕턴스 1V FAST", "투자율 CC 10mA SLOW2"
- [프리셋] 목록에서 이름을 고르면 그 조건이 화면에 채워집니다.
  연결 전이면 [연결]할 때, 연결 중이면 [연결 중 적용]을 눌러야 계측기에 반영됩니다.
- 같은 이름으로 저장하면 덮어쓸지 묻습니다. 필요 없는 프리셋은 고른 뒤 [삭제]를 누릅니다.

CSV 기록
- CSV와 표의 "측정조건" 열에 그 행을 잴 때의 신호 종류·레벨, SPEED, DC 바이어스가 기록됩니다.
  예) CV 1.000V / SPEED MEDIUM / DC바이어스 OFF
- "변경 안 함"으로 둔 항목도 계측기에서 실제 값을 읽어 기록합니다.

복원
- [연결 해제]를 누르거나 프로그램을 끌 때, 프로그램이 바꾼 항목만 연결하기 전 값으로 되돌립니다.
- "연결 해제하면 … 되돌림" 스위치를 끄면 되돌리지 않고, 바꾼 조건을 계측기에 그대로 둡니다
  (예: 계측기를 이 조건으로 계속 쓰고 싶을 때). 스윕·복소 투자율 측정의 임시 조건은 스위치와 관계없이 되돌립니다.
- USB가 빠지면 그 순간에는 되돌릴 수 없습니다. 자동 재연결되면 같은 조건을 다시 보내고,
  원래 값은 처음 연결하기 전 값을 기억해 둡니다.
- 원래 값은 설정 파일에도 저장해 둡니다. 프로그램이 비정상 종료되었거나
  [재연결 취소]로 끝내서 되돌리지 못했으면, 다음에 같은 계측기에 [연결]할 때
  "원래 값으로 되돌린 뒤 연결할까요?"라고 묻습니다. [예]를 누르면 되돌립니다.

확인
- 계측기가 실제로 받은 값을 읽어 로그에 표시합니다 (예: "측정 조건: 정전압 CV 0.500 V").
  허용 범위를 벗어나 받지 않은 경우 "※ 계측기가 값을 받지 않았습니다"라고 표시됩니다.


■ 복소 투자율 측정 (μ′, μ″) - [복소 투자율] 탭
------------------------------------------------------------
토로이달 코어에 코일을 감아 주파수를 바꿔 가며 Z, θ를 재고
복소 투자율 μ′(실수부), μ″(허수부)와 손실계수 tanδ를 계산합니다.
결과는 그래프(가로 주파수 로그, 왼쪽 μ′ 실선, 오른쪽 μ″ 점선)와 CSV로 남습니다.
[인덕턴스 기록] 탭의 기능과 설정은 그대로이며, [1. 연결]과 아래 로그는 두 탭이 같이 씁니다.

준비
- 계측기에서 OPEN / SHORT 보정을 먼저 합니다 (측정 시작할 때 한 번 더 묻습니다).
  보정하지 않으면 리드선·지그의 영향으로 고주파 값이 크게 틀어집니다.
- [1. 연결]로 계측기를 연결한 뒤 [복소 투자율] 탭을 누릅니다.

1. [시료]
   - 시료명, 턴 수 N을 입력합니다.
   - 외경 OD, 내경 ID, 높이 h를 mm로 입력하면 le, Ae가 자동으로 계산됩니다.
       le = π·(OD − ID) / ln(OD/ID)   [mm]
       Ae = h·(OD − ID) / 2            [mm²]
     카탈로그 값 등을 쓰려면 "le·Ae 직접 입력"을 켜고 le, Ae를 직접 입력합니다.
   - 권선 저항 Rw: [DCR 측정]을 누르면 계측기의 Rdc로 재서 채웁니다 (직접 입력도 가능).
     Rw는 μ″ 계산에서 빼므로, 저주파 μ″가 정확하려면 꼭 채우세요.
     Rdc는 잴 때만 DC 레인지(AC와 별도)를 자동으로 바꿔 재고(HOLD이면 수십 mΩ 권선이 UNDERFLOW로 나오기 때문),
     끝나면 원래대로 되돌립니다. 그래도 값이 없으면(응답 -9.99999E+33) 다섯 번까지 다시 재고,
     그래도 없으면 오류를 띄웁니다. 이때는 멀티미터 등으로 잰 값을 직접 입력하세요.

2. [측정 설정]
   - 시작·끝 주파수 (기본 1k ~ 8M, 계측기 범위 4 Hz ~ 8 MHz), 점 수 (기본 100)
   - 간격: 로그(기본) 또는 선형
   - 측정 신호: V / CV / CC 와 값 (기본 CC 1 mA - 낮은 레벨, 코어의 초투자율 측정용)
   - SPEED (FAST/MED/SLOW/SLOW2), 평균 (1 ~ 256), 점 사이 대기 (ms)
   이 조건은 측정하는 동안만 계측기에 적용하고, 끝나면(중지·오류 포함) 측정 전 값으로 되돌립니다.
   측정 중에는 PAR1 = Z, PAR2 = θ, PAR3·PAR4 = OFF, 트리거 EXT로 바뀝니다.

3. [측정 시작] → "OPEN/SHORT 보정을 했습니까?" 창에서 [예]
   - 점마다 주파수 설정 → 측정 → Z, θ, 모니터 전압·전류(Vmoni, Imoni)를 받습니다.
   - 그래프가 실시간으로 그려지고 진행 막대가 찹니다.
   - [중지]를 누르면 지금 점까지 재고 멈춥니다. 그때까지 받은 값은 저장됩니다.
   - 통신 오류가 나도 그때까지 받은 값은 저장하고 멈춥니다.

4. 결과
   - 끝나면 저장 폴더([인덕턴스 기록] 탭의 [3. 저장]과 같은 폴더)에 자동 저장합니다.
       MU_시료명_N10턴_2026-11-13_14-30-00.csv
       MU_시료명_N10턴_2026-11-13_14-30-00.png  (그래프, 1200×700)
   - [CSV 다른 이름으로 저장], [그래프 PNG 저장]으로 다른 곳에도 저장할 수 있습니다.

계산 (μ0 = 4π×10⁻⁷ H/m, ω = 2πf)
   Rs = Z·cosθ,  Xs = Z·sinθ,  Ls = Xs / ω
   μ′ = Ls·le / (μ0·N²·Ae)
   μ″ = (Rs − Rw)·le / (ω·μ0·N²·Ae)
   tanδ = μ″ / μ′

CSV 형식
   위쪽: 측정 조건 (일시, 시료명, N, OD/ID/h, le, Ae, Rw, 측정 신호, SPEED, 평균, 주파수,
         계측기, 계측기 조건, 상태(완료/중지됨/오류), 경고)
   빈 줄 한 줄
   아래: f [Hz], Z [Ω], θ [°], Rs [Ω], Ls [H], μ′, μ″, tanδ, Vmoni [V], Imoni [A]

경고 (화면에 빨간 글씨, 로그와 CSV에도 기록)
- "권선 자기공진 의심 ... 신뢰 구간은 대략 ○○ 이하"
  고주파에서 μ′가 음수가 되거나 θ의 부호가 바뀌었을 때. 권선의 자기공진 때문에 공진점 근처부터 값이 틀어집니다.
  신뢰 구간은 공진 주파수의 절반 정도로 어림한 값입니다. 더 높은 주파수는 턴 수를 줄여 다시 재세요.
- CC 모드: Imoni(실제 전류)를 설정 전류와 비교합니다 (±10%).
  · "설정보다 전류가 많이 흐름 (설정 10 µA, 실제 최대 86 µA, 1kHz~23kHz)"
    설정 전류가 너무 작아 계측기가 그만큼 작은 신호를 못 냅니다. 레벨을 올리세요 (예: 0.1 mA).
  · "설정 전류를 유지하지 못함 (설정 100 µA, 실제 최소 79 µA, 1.5MHz부터) - ... 출력 전압 한계"
    고주파에서 임피던스가 커져 계측기의 출력 전압(약 1 V)으로는 설정 전류를 흘릴 수 없습니다.
    턴 수를 줄이거나 레벨을 낮추세요.
- V / CV 모드: "측정 레벨이 일정하지 않음 ..., CC 모드 권장"
  Imoni가 첫 점보다 ±10% 넘게 변했을 때. 투자율은 자계 세기에 따라 달라지므로 CC 모드로 다시 재세요.

넓은 주파수를 잴 때 (예: 1 kHz ~ 8 MHz)
- 턴 수가 많으면 저주파는 잘 재지만, 고주파에서 자기공진과 출력 전압 한계에 걸립니다.
- 두 번 나눠 재는 것을 권장합니다: 많은 턴(예: 10턴)으로 1 kHz ~ 1 MHz, 적은 턴(예: 3~5턴)으로 100 kHz ~ 8 MHz.
  겹치는 구간(100 kHz ~ 1 MHz)에서 μ′, μ″가 맞으면 이어 붙여 쓰면 됩니다.

계측기 없이 연습
- "데모 모드"로 연결하면 가상 코어(μi = 10000, 차단 주파수 200 kHz, OD 25 / ID 15 / h 10 mm,
  10턴, 권선 저항 0.05 Ω)의 값이 나옵니다. 기본 입력값 그대로 [DCR 측정] → [측정 시작]을 하면
  저주파 μ′ ≈ 10000, μ″ 최대 ≈ 5000 (200 kHz 근처)인 그래프가 나옵니다.


■ 스윕 측정 - [스윕 측정] 탭 (공식 프로그램의 Sweep Measurement)
------------------------------------------------------------
주파수 또는 측정 신호(V·CV·CC)를 바꿔 가며 계측기의 PAR1~PAR4 값을 잽니다.
1. [스윕 항목]을 고릅니다: 주파수 [Hz] / 개방전압 V [V] / 정전압 CV [V] / 정전류 CC [mA]
2. 시작·끝·점 수·간격(로그/선형)을 넣고 [점 목록 만들기]를 누릅니다.
   점 목록은 직접 고쳐도 됩니다 (쉼표나 줄바꿈으로 구분, 최대 5000점).
3. 반복 횟수, 반복 사이 대기(초), 점 사이 대기(ms)를 정하고 [측정 시작]을 누릅니다.
4. 측정값은 계측기에 지금 켜진 PAR1~PAR4입니다. 바꾸려면 [계측기 설정] 탭의 PAR1~PAR4를 바꾸세요.
5. 끝나면 저장 폴더에 SWEEP_시료명_날짜_시간.csv / .png 를 자동 저장합니다.
   그래프는 왼쪽 축이 PAR1, 오른쪽 축(점선)이 PAR2이고, 반복마다 선이 하나씩 생깁니다.
- 측정하는 동안만 신호 종류·주파수를 바꾸고, 끝나면 원래대로 되돌립니다.
- 계측기가 어떤 점의 값을 받지 않으면(허용 범위 밖) 그 점에서 멈추고, 그때까지 받은 값은 저장합니다.


■ 계측기 설정과 화면 캡처 - [계측기 설정] 탭 (공식 프로그램의 Set, Hard Copy)
------------------------------------------------------------
[계측기에서 읽기]를 누르면 측정 조건 26가지(주파수, 측정 신호, 리밋, 레인지, LOW Z, SPEED,
평균, 트리거·트리거 지연, 동기 출력, DC 바이어스, PAR1~PAR4, Rdc 지연, 전원 주파수)를 표로 보여 줍니다.
- 바꿀 항목의 [새 값] 칸에 값을 넣거나 고른 뒤 [바꾼 값 적용]을 누릅니다.
  계측기가 받은 항목은 초록색, 받지 않은 항목은 빨간색으로 표시됩니다.
- 여기서 바꾼 값은 계측기에 그대로 남습니다 (되돌리지 않음).
  단, [인덕턴스 기록] 탭의 측정 조건으로 바꾼 항목은 연결을 해제할 때 원래대로 돌아갑니다 (복원 스위치가 켜져 있을 때).
- [컬러로 캡처] / [흑백으로 캡처]: 계측기 화면을 받아 저장 폴더에 SCREEN_날짜_시간.png 로 저장합니다.


■ 정확도·측정 범위 계산 - [계산 도구] 탭 (공식 프로그램의 Calc Accuracy, Calc Measure Range)
------------------------------------------------------------
계측기 없이 계산만 합니다. 숫자는 1k, 100u, 2.2n 처럼 접두어를 붙여 써도 됩니다.
- 정확도 계산: 파라미터(Z-θ, Cs-D, Cp-D, Ls-Q, Lp-Q, Rdc), 측정값, 주파수, 레벨, 레인지,
  SPEED, 케이블 길이, DC 바이어스, 온도를 넣고 [계산] → 측정값의 오차 범위(%)와 D·Q·θ 범위.
  [자동 레인지]는 측정값에 맞는 레인지를 고릅니다. 레인지가 맞지 않으면 빨간 경고가 나옵니다.
- 측정 범위 계산: 레인지·주파수·레벨을 넣고 [계산] → 그 레인지로 잴 수 있는 |Z|, L, C 범위.
- 계산식과 표는 HIOKI 공식 프로그램(1.4.0)의 IM3536 부분을 그대로 옮겼습니다.


■ USB 자동 재연결
------------------------------------------------------------
측정 중에 USB 케이블이 빠지거나 계측기 전원이 꺼졌다 켜지면
화면에 "USB 연결 끊김 - 다시 연결되기를 기다리는 중..."이 빨간색으로 표시됩니다.
케이블을 다시 꽂거나 계측기를 켜면 몇 초 안에 "띵" 소리와 함께 자동으로 다시 연결됩니다.

- [연결]을 다시 누를 필요가 없고, 같은 CSV 파일에 이어서 기록됩니다.
- 다른 USB 단자에 꽂아 COM 번호가 바뀌어도 HIOKI 장비를 찾아 연결합니다.
- 기다리는 것을 그만두려면 [재연결 취소]를 누릅니다.
- 끊어진 순간 진행 중이던 측정 한 번과 연속 측정은 멈춥니다.
  재연결 후 다시 측정하세요.
- 이 기능을 끄려면 [1. 연결]의 "USB 자동 재연결" 스위치를 끕니다.


■ 시료를 하나씩 바꿔 가며 측정할 때 (선택)
------------------------------------------------------------
버튼을 누르는 순간에 새로 측정한 값을 받고 싶으면

1. 화면 아래 "직접 명령" 칸에 :TRIG EXT 를 입력하고 Enter를 누릅니다.
2. "누를 때마다 새로 측정" 을 체크합니다.

원래대로 되돌리려면 직접 명령 칸에 :TRIG INT 를 보내고 체크를 해제합니다.


■ 자동 업데이트
------------------------------------------------------------
하루에 한 번 인터넷으로 새 버전이 있는지 확인합니다.
그날 처음 프로그램을 켤 때 확인하고, 같은 날 여러 번 켜도 다시 확인하지 않습니다.
프로그램을 켜 둔 채 날짜가 바뀌면 그때 한 번 확인합니다.
새 버전이 있으면 "지금 업데이트할까요?"라고 묻고,
[예]를 누르면 새 버전을 받아 프로그램을 다시 시작합니다.
설정과 측정 데이터는 그대로 남습니다.

- 직접 확인하려면 화면 아래 [업데이트 확인] 버튼을 누릅니다.
- 자동으로 확인하지 않으려면 "하루 한 번 업데이트 확인" 스위치를 끕니다.
- 측정 중이라 업데이트를 미룬 경우에는 측정이 끝난 뒤 다시 확인합니다.
- 인터넷 문제로 확인에 실패하면 다음에 프로그램을 켤 때 다시 확인합니다.
- 인터넷이 안 되는 PC에서는 확인만 실패하고(로그에 기록) 그대로 사용할 수 있습니다.
- 프로그램 폴더가 쓰기 금지된 곳(Program Files 등)에 있으면 업데이트할 수 없습니다.
  바탕화면이나 문서 폴더에 두고 사용하세요.
- 개발자 정보와 버전은 [정보] 버튼에서 볼 수 있습니다.


■ 구글 스프레드시트로 옮기기
------------------------------------------------------------
1. 구글 스프레드시트를 열고 [파일] → [가져오기] → [업로드]를 누릅니다.
2. CSV 파일(문서\LCR_Data 폴더)을 끌어다 놓습니다.
3. "새 시트 삽입" 또는 "현재 시트에 행 추가"를 고르고 [데이터 가져오기]를 누릅니다.

엑셀에서는 CSV 파일을 더블클릭하면 바로 열립니다.


■ 문제가 생겼을 때
------------------------------------------------------------
- COM 포트 목록이 비어 있거나 ★ 표시가 없음
  → USB 케이블 연결과 USB 드라이버 설치를 확인하고 [새로고침]을 누르세요.

- "응답 없음" 메시지
  → 계측기 인터페이스 설정이 USB인지 확인하세요.
  → 계측기가 일반 LCR 측정 화면인지 확인하세요.
    연속 측정(CONTINUOUS) 모드에서는 측정값을 받을 수 없습니다.
    대신 위의 "여러 주파수로 한 번에 측정하기"를 사용하세요.

- "응답 값 개수가 파라미터 개수와 다릅니다" 경고
  → [연결 해제] 후 다시 [연결]하세요.
    측정 도중 계측기 설정을 바꾸면 이 경고가 나옵니다.

- 화면 아래에 "저장 대기" 표시가 빨간색으로 나옴
  → 저장 중인 CSV 파일이 엑셀에서 열려 있는 상태입니다.
    엑셀을 닫으면 다음 측정 때 밀린 데이터까지 함께 저장됩니다.

- 단축키(F9)를 눌러도 반응이 없음
  → 로그에 "다른 프로그램이 쓰고 있습니다"가 있으면 다른 키(F6~F12)를 고르세요.
  → 관리자 권한으로 실행한 엑셀에는 입력할 수 없습니다. 엑셀을 일반 권한으로 실행하세요.

- 계측기 없이 화면만 연습해 보고 싶을 때
  → "데모 모드"를 체크하고 [연결]을 누르면 가상 값으로 연습할 수 있습니다.

문제가 계속되면 화면 아래 로그 창의 내용을 복사해서 담당자에게 보내 주세요.
